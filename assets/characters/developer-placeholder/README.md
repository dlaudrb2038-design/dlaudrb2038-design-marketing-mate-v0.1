# Developer placeholder resource directory

Phase 1 경로 골격이며 최종 개인화 에셋이 아닙니다. 현재 캐릭터 창은
CSS 도형과 `DEVELOPMENT ASSET` 표시만 사용합니다.

atlas.png, manifest.json, 96×96 프레임·앵커 및 20 clip 로더는 Phase 2에서
구현·검증합니다. 이 폴더만으로 에셋 계약이나 릴리스 합격을 충족하지 않습니다.

공식 경로는 `assets/characters/developer-placeholder/`입니다. 제품 설계서와
코드·문서·검증에서 이 명칭을 일관되게 사용하며, Phase 2 로더도 이 경로를 기준으로 합니다.
